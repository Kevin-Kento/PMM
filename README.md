# 🤝 Voluntinder(ボランティンダー)

**スワイプで見つける、あなたのボランティア。**

Voluntinder は、ボランティア募集を Tinder ライクなスワイプ UI で探せる掲示板アプリです。
募集がカードになって次々と表示されるので、直感的に「興味あり / スキップ」を選べます。

## 主な機能

- 🃏 **スワイプで探す** — 募集カードを右スワイプで「興味あり」、左スワイプで「スキップ」。ドラッグ&ボタン操作の両対応
- 👀 **カードをタップで詳細表示** — 活動内容・持ち物などの詳しい説明を確認
- ↩ **アンドゥ** — 間違えてスワイプしてもひとつ前に戻せる
- 💖 **興味ありリスト** — 右スワイプした募集を一覧で見返せる
- 📝 **募集の投稿** — カテゴリー・日時・場所などを入力して、自分の募集をデッキに追加
- 💾 **ローカル保存** — スワイプ履歴と投稿はブラウザの localStorage に保存

## 技術スタック

- [React 18](https://react.dev/) + TypeScript
- [Vite](https://vitejs.dev/)
- 外部 UI ライブラリなし(スワイプ操作は Pointer Events で自前実装)

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果のプレビュー
```
